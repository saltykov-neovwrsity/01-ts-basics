# Основи TypeScript

Домашнє завдання №1: типізація даних, функцій та асинхронних операцій.
Проєкт містить вісім практичних завдань на TypeScript і запускається через Vite.

**Автор:** Салтиков Андрій.

## Технології

- **TypeScript** — статична типізація зі строгим режимом `strict`.
- **Vite** — сервер для розробки та збірка проєкту.
- **Axios** — HTTP-запити.
- **ESLint** і **Prettier** — перевірка коду та форматування.

## Запуск локально

Потрібні Node.js і npm. Діапазон підтримуваних версій Node.js у `package.json`:
`^20.19.0 || ^22.13.0 || >=24`.

1. Клонуйте репозиторій та перейдіть у папку проєкту:

   ```bash
   git clone https://github.com/saltykov-neovwrsity/01-ts-basics.git
   cd 01-ts-basics
   ```

2. Встановіть залежності:

   ```bash
   npm install
   ```

3. Запустіть сервер для розробки:

   ```bash
   npm run dev
   ```

4. Відкрийте адресу, яку Vite покаже в терміналі — зазвичай
   `http://localhost:5173/`.
5. Натисніть **F12** і перейдіть на вкладку **Console**, щоб побачити результати.

Усі завдання підключені в `src/main.ts` і виконуються під час завантаження сторінки.
Результати виводяться через `console.log` та `console.table`.
Щоб повторити виконання, оновіть сторінку.

Завдання 7 виводить повідомлення приблизно через дві секунди.
Завдання 8 потребує доступу до інтернету: воно отримує дописи з
[JSONPlaceholder](https://jsonplaceholder.typicode.com/posts). У разі невдалого
запиту повідомлення про помилку з’явиться в консолі.

## Завдання

| Файл            | Тема                  | Реалізація                                                              |
| --------------- | --------------------- | ----------------------------------------------------------------------- |
| `src/task-1.ts` | Базові типи           | Змінні з типами `string`, `number` та `boolean`.                        |
| `src/task-2.ts` | Інтерфейси            | `Product` із полем `readonly id` та необов’язковим `description`.       |
| `src/task-3.ts` | Типізація масивів     | Масиви рядків, чисел та об’єктів `Product`.                             |
| `src/task-4.ts` | Функції               | `printUserInfo` з необов’язковим параметром `email` і типом `void`.     |
| `src/task-5.ts` | Літеральні типи       | Тип `Status` зі значеннями `loading`, `success` та `error`.             |
| `src/task-6.ts` | Узагальнення          | Функція `getFirstElement<T>` для отримання першого елемента масиву.     |
| `src/task-7.ts` | Асинхронні операції   | `getMessage`, яка повертає `Promise<string>` із затримкою.              |
| `src/task-8.ts` | Типізація HTTP-запиту | Отримання `Post[]` через Axios і виведення відомостей про перший допис. |

У завданнях 5 і 6 залишені закоментовані приклади некоректних аргументів.
Для перевірки можна розкоментувати один із них і виконати `npm run typecheck`:
TypeScript повідомить про невідповідність типів. Після перевірки закоментуйте
приклад знову, щоб проєкт проходив збірку.

## Команди

| Команда                | Призначення                                               |
| ---------------------- | --------------------------------------------------------- |
| `npm run dev`          | Запустити сервер для розробки.                            |
| `npm run typecheck`    | Перевірити типи без створення JavaScript-файлів.          |
| `npm run lint`         | Перевірити код через ESLint.                              |
| `npm run format:check` | Перевірити форматування через Prettier.                   |
| `npm run format`       | Автоматично відформатувати файли проєкту.                 |
| `npm run build`        | Перевірити типи та створити збірку в `dist/`.             |
| `npm run preview`      | Локально переглянути готову збірку після `npm run build`. |

## Структура проєкту

```text
01-ts-basics/
├── src/
│   ├── main.ts          # Підключення всіх завдань
│   └── task-1.ts … task-8.ts
├── index.html           # Сторінка з інструкцією перегляду результатів
├── package.json         # Залежності та npm-команди
├── package-lock.json    # Зафіксовані версії залежностей
├── tsconfig.json        # Налаштування TypeScript
├── eslint.config.js     # Налаштування ESLint
├── .prettierrc.json      # Налаштування Prettier
├── .gitignore           # Виключення для Git
└── README.md
```

Папки `node_modules/` і `dist/` створюються локально та не додаються до Git.
